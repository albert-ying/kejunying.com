NAME

ClockBase Agent

SYNOPSIS

The AI Agent Analysis page lets you explore the comparisons an AI agent designed across mouse and human RNA-seq and human DNA methylation studies.

DESCRIPTION

ClockBase is the web application accompanying the ClockBase Agent manuscript.

EXAMPLE

You can view the data as a sortable table or an interactive volcano plot, filter by various criteria, and click any entry to open a detailed report dashboard.

OUTPUT

the agent-generated mini-paper for every intervention (/api/interventions/report/{case_id}/output and /parsed)
