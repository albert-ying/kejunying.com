ADMET-EvO: a self-evolving scientific agent for sustained research across heterogeneous tasks

Zhou, Y., Wang, Y., Wang, J., Zhu, H., ..., Ying, K., ..., Zhang, O.

arXiv · 2026 · Preprint

Open paper

Summary

ADMET-EvO is a scientific agent for absorption, distribution, metabolism, excretion and toxicity prediction across assays, datasets and chemical domains. It defines endpoints, generates falsifiable hypotheses and tests changes to data, features and models using accumulated evidence.
