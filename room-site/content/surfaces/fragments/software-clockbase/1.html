NAME

ClockBase

SYNOPSIS

Upload your own data or browse GEO datasets, then run aging-clock predictions and statistical analysis with multiple clocks.

DESCRIPTION

ClockBase is the web application accompanying the ClockBase Agent manuscript.

EXAMPLE

Upload your own data or browse GEO datasets, then run aging-clock predictions and statistical analysis with multiple clocks.

OUTPUT

a manual analysis interface (per-GSE clock predictions, correlation plots, group-comparison plots with ANCOVA, Manhattan-style volcano browsing with category / score / FDR / effect-size filters)
