cd methylgpt/package
pip install -e .                 # numpy, pandas, torch
pip install -e ".[examples]"     # plus jupyter and matplotlib for the tutorial

The weights are attached to the release v1.1.2 of this repository. Download its eight files (config.json, vocab.txt, core.npz, weights.pt, weights_run2.pt, weights_run3.pt, weights_age_stage.pt and checksums.sha256) into one folder named methylgpt-1.1 and check them with shasum -a 256 -c checksums.sha256 inside that folder; package/methylgpt-1.1.checksums.sha256 holds the same checksums.

DESCRIPTION

MethylGPT is a foundation model that learns the co-methylation structure of the human DNA methylome without labels from 169,010 public DNA methylation profiles (145,700 for training) and reads any subset of its 49,156 CpGs, from 27K, 450K, EPIC v1 or EPIC v2 arrays.

EXAMPLE

import pandas as pd
from methylgpt import MethylGPT

model = MethylGPT.from_pretrained("methylgpt-1.1")     # path to the bundle folder; GPU if available
betas = pd.read_csv("betas.csv", index_col=0)          # samples x CpG IDs, beta values in [0, 1]
pred = model.predict(betas)                            # age, sex, tissue and the distilled clock outputs

OUTPUT

Trained further on age, sex, tissue and 25 published clock outputs, it returns imputed values, latent scores, sample embeddings, age, sex, tissue and the distilled clock outputs.
